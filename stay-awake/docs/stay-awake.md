# StayAwake - 页面保活

## 功能

防止网页因闲置超时自动退出登录。

### 特性

- 🔒 **指定网站生效** — 只在你需要的网站上激活，不影响其他页面
- 🖱️ **智能闲置检测** — 用户操作时静默，离开后自动保活
- ⌨️ **多种模拟策略** — 鼠标移动、键盘事件、或两者兼有
- 📊 **状态指示** — 页面右下角小圆点显示保活状态
- ⚙️ **灵活配置** — 闲置时间、保活间隔、生效网站均可自定义

### 使用方法

1. 安装 [Tampermonkey](https://www.tampermonkey.net/)
2. 安装本脚本
3. 点击 Tampermonkey 图标 → StayAwake → 设置
4. 配置需要保活的网站（逗号分隔）
5. 脚本会自动在闲置后开始保活

### 配置说明

| 选项 | 默认值 | 说明 |
|------|--------|------|
| 启用保活 | 开启 | 全局开关 |
| 闲置时间 | 5 分钟 | 用户无操作多久后开始保活 |
| 保活间隔 | 5 分钟 | 每次保活操作的间隔 |
| 模拟策略 | 鼠标+键盘 | 选择模拟的事件类型 |
| 生效网站 | 所有站 | 逗号分隔的域名列表，留空则所有站生效 |

### 工作原理

1. 监听页面上的鼠标移动、键盘输入、点击等真实用户操作
2. 记录最后操作时间
3. 当闲置时间超过设定值，开始定时模拟用户操作
4. 用户回到页面时，自动停止保活
