# 🧲 磁力链接预览

> 浏览网页时看到磁力链接，点一下就能看到里面有什么——文件列表、视频截图，一目了然。

## 痛点

- 磁力链接只是一串乱码，完全不知道里面是什么文件
- 下载前想知道有没有字幕、有没有广告文件、视频大概多大
- 不想为了看一眼内容就去装一个 BT 客户端

## 核心功能

- 🔍 **一键预览** — 点击页面上的磁力链接，弹窗展示完整信息
- 📁 **文件列表** — 显示种子内所有文件及大小（从 itorrents.org / btdig.com 获取）
- 🖼 **视频截图** — 预览视频内容截图（从 whatslink.info 获取）
- 📋 **一键复制** — 复制磁力链接到剪贴板

## 三层数据源

| 数据源 | 提供内容 | 网络要求 |
|--------|---------|---------|
| whatslink.info | 文件名、大小、视频截图 | 直连 |
| itorrents.org | 完整文件列表（解析 .torrent） | 直连 |
| btdig.com | 文件列表（HTML 解析） | 需代理（自动 fallback） |

> 按顺序自动调用：直连源优先，失败后尝试代理源，确保最大可用性。

## 使用方式

1. 安装 [Tampermonkey](https://www.tampermonkey.net/) 扩展
2. 点击上方「安装脚本」链接安装
3. 浏览任意网页，磁力链接会自动高亮为紫色
4. 点击磁力链接即可预览

## 兼容性

- ✅ 支持 `<a>` 标签中的磁力链接
- ✅ 支持纯文本中的磁力链接（自动转换为可点击链接）
- ✅ 支持 input / textarea 中的磁力链接（旁边出现预览按钮）
- ✅ 监听动态内容（SPA、懒加载等）
