# 🔐 密码显示与复制 | Password Show & Copy

一键显示、复制网页密码框内容的油猴脚本，支持加密混淆显示。

## ✨ 功能

- **👁️ 显示密码** — 点击眼睛图标，密码明文显示
- **📋 一键复制** — 点击复制按钮，密码直接进入剪贴板
- **🔒 加密显示** — 开启后密码用偏移算法混淆，自己看得懂、别人看不懂
- **⚙️ 油猴菜单设置** — 通过 Tampermonkey 菜单管理开关和加密参数

## 🔧 使用方法

### 安装
1. 安装 [Tampermonkey](https://www.tampermonkey.net/) 浏览器扩展
2. 点击 [安装脚本](https://raw.githubusercontent.com/liuyunss/browser-toolkit/main/scripts/show-password.user.js)
3. 确认安装

### 基本操作
- 在任何网站的密码输入框旁会出现 **👁️** 和 **📋** 两个按钮
- 点击 👁️ 切换显示/隐藏密码
- 点击 📋 复制密码到剪贴板

### 加密显示
适用于"想看密码但不想被旁人看到"的场景：

1. 点击浏览器右上角 Tampermonkey 图标
2. 点击「🔒 加密显示: 已关闭」开启
3. 点击「⚙️ 设置偏移量」配置偏移规则

**偏移规则示例**（默认：字母偏移7，数字偏移3）：
| 原始 | 加密 |
|------|------|
| a    | h    |
| A    | H    |
| 1    | 4    |
| 3    | 6    |
| MyP@ss123 | TfW@zz456 |

你自己知道偏移量，看到加密结果就能认出是哪个密码，别人看到只是一串乱码。

### 菜单说明
点击 Tampermonkey 图标可看到以下菜单项：

- **🟢/🔴 密码工具** — 开启/关闭脚本
- **🔒/🔓 加密显示** — 开启/关闭加密显示
- **⚙️ 设置偏移量** — 修改加密偏移参数

## 🔐 隐私

- 本脚本不收集、不上传任何数据
- 所有数据存储在本地浏览器中（Tampermonkey 的 GM_setValue）
- 复制密码仅在本地剪贴板操作
