# 💾 FormSave - 表单自动保存

自动保存表单内容，刷新/崩溃后一键恢复，防止填写丢失。

## ✨ 功能

- **自动保存** — 输入时实时保存，页面关闭兜底
- **一键恢复** — 页面加载后自动检测，悬浮按钮一键恢复
- **智能暂停** — 页面加载不保存，首次用户操作后才开始
- **保存范围** — 只保存用户修改过的字段，不重复保存
- **安全排除** — 自动排除金融/支付页面
- **多表单** — 同一页面支持多个表单
- **存储管理** — 按站点/总量双限制，FIFO 自动清理

## 📥 安装

1. 安装 [Tampermonkey](https://www.tampermonkey.net/) 浏览器扩展
2. 点击 [安装脚本](https://raw.githubusercontent.com/liuyunss/browser-toolkit/main/form-save/form-save.user.js)

## ⚙️ 配置

点击 Tampermonkey 图标 → FormSave → 设置：

| 参数 | 默认值 | 说明 |
|------|--------|------|
| 启用保存 | 开启 | 关闭后停止保存和恢复 |
| 站点上限 | 50KB | 单个站点最大存储 |
| 总量上限 | 5000KB | 所有站点总存储 |
| 保留天数 | 7天 | 超过天数自动清理 |
| 恢复延迟 | 100ms | 下拉框字段间延迟 |
| 排除域名 | 空 | 逗号分隔，这些站点不生效 |

## 🔒 安全

- 密码字段 (`type="password"`) **不保存**
- 金融/支付页面自动排除（可自定义）
- 只保存用户修改过的字段
- 所有数据本地存储，不上传任何服务器
