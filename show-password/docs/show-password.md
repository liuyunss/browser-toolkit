# 🔐 密码显示与复制

在所有网站的密码输入框旁添加显示/隐藏密码和复制密码按钮。

## ✨ 功能

- **显示/隐藏密码** — 眼睛按钮切换明文与圆点
- **一键复制** — 复制按钮直接复制真实密码到剪贴板
- **密码常显** — 可配置始终明文显示，隐藏眼睛按钮
- **关闭眼睛** — 隐藏眼睛按钮，密码保持圆点，仅复制
- **广泛兼容** — 支持 React/Vue 等框架的密码输入框
- **动态监听** — 自动检测页面新出现的密码框

## 📥 安装

1. 安装 [Tampermonkey](https://www.tampermonkey.net/) 浏览器扩展
2. 点击 [安装脚本](https://raw.githubusercontent.com/liuyunss/browser-toolkit/main/show-password/show-password.user.js)

## ⚙️ 配置

点击 Tampermonkey 图标 → 密码显示与复制 → 设置：

| 参数 | 默认值 | 说明 |
|------|--------|------|
| 启用脚本 | 开启 | 关闭后密码框不再显示按钮 |
| 始终显示密码 | 关闭 | 密码直接明文显示，隐藏眼睛按钮 |
| 关闭眼睛 | 关闭 | 隐藏眼睛按钮，密码保持圆点，仅复制 |

### 三种模式

| 模式 | 眼睛按钮 | 输入框 | 复制按钮 |
|------|---------|--------|---------|
| 默认 | ✅ 显示 | 圆点 ↔ 明文切换 | ✅ 显示 |
| 密码常显 | ❌ 隐藏 | 始终明文 | ✅ 显示 |
| 关闭眼睛 | ❌ 隐藏 | 始终圆点 | ✅ 显示 |

## 🔒 安全

- 复制按钮始终复制真实密码，不受眼睛状态影响
- 所有数据本地存储，不上传任何服务器
- 表单提交时发送真实密码，不会发送乱码
