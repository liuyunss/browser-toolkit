# 🔐 密码显示与复制

在所有网站的密码输入框旁添加显示/隐藏密码和复制密码按钮。

## ✨ 功能

- **显示/隐藏密码** — 眼睛按钮切换明文与圆点
- **一键复制** — 复制按钮直接复制真实密码到剪贴板
- **鼠标悬停预览** — 鼠标移入密码框时临时显示明文，移出后恢复
- **关闭眼睛** — 隐藏眼睛按钮，密码保持圆点，仅复制
- **广泛兼容** — 支持 React/Vue 等框架的密码输入框，不破坏页面布局
- **动态监听** — 自动检测页面新出现的密码框

## 📥 安装

1. 安装 [Tampermonkey](https://www.tampermonkey.net/) 浏览器扩展
2. 点击 [安装脚本](https://raw.githubusercontent.com/liuyunss/browser-toolkit/main/show-password/show-password.user.js)

## ⚙️ 配置

点击 Tampermonkey 图标 → 密码显示与复制 → 设置：

| 参数 | 默认值 | 说明 |
|------|--------|------|
| 启用脚本 | 开启 | 关闭后密码框不再显示按钮 |
| 关闭眼睛 | 关闭 | 隐藏眼睛按钮，密码保持圆点，仅复制 |
| 鼠标悬停预览 | 开启 | 鼠标移入密码框时临时显示明文 |

### 三种模式

| 模式 | 眼睛按钮 | 输入框 | 复制按钮 | 悬停预览 |
|------|---------|--------|---------|---------|
| 默认 | ✅ 显示 | 圆点 ↔ 明文切换 | ✅ 显示 | ✅ 开启 |
| 关闭眼睛 | ❌ 隐藏 | 始终圆点 | ✅ 显示 | ✅ 开启 |

### 鼠标悬停预览

默认模式下，将鼠标移入密码输入框会临时切换为明文显示，移出后自动恢复为圆点。该功能：
- 不影响手动眼睛按钮的切换状态
- 可在设置中独立开关

## 🔒 安全

- 复制按钮始终复制真实密码，不受眼睛状态影响
- 所有数据本地存储，不上传任何服务器
- 表单提交时发送真实密码，不会发送乱码

## 🛠 技术特性

- **不破坏页面布局** — 按钮以 inline-flex 方式插入，不修改父元素的 CSS 属性
- **MutationObserver 暂停机制** — 注入按钮时暂停观察，避免无限循环
- **剪贴板回退链** — GM_setClipboard → navigator.clipboard → execCommand，兼容各种环境
- **dataset 标记在成功后设置** — 失败时可重试
